# Контроллер ESP32

Самостоятельный репозиторий C/C++ и ESP-IDF. Точка входа и конфигурация — firmware/main/, самостоятельные компоненты — firmware/components/, make build / make flash / make monitor запускаются отсюда. scripts/esp.sh подготавливает SDK и определяет порт.

Это учебный проект русскоязычного Node.js/TypeScript разработчика. Объясняй небольшими шагами, не считай понимание подтверждённым наличием кода. Если рядом существует ../docs/, перед работой читай README.md, PROGRESS.md и нужный этап ROADMAP.md оттуда, после содержательной работы обновляй PROGRESS.md. При отдельном клонировании используй README.md этого репозитория.

ESP32-D0WD-V3 и PMS5003; точная схема платы не установлена. Не назначай GPIO и питание без проверки документации. Wi-Fi и прежняя mock HTTPS-цепочка проверены на устройстве; сырой UART PMS5003 подтверждён. Полный приём реализован, актуальный статус его аппаратной проверки — в ../docs/PROGRESS.md. Не утверждай физическую проверку без логов.

Секреты задаются в firmware/main/config/*.local.h, не коммитить и не выводить их. Не публиковать build/ и .local/: там могут быть секреты из прошивки. Backend живёт в отдельном репозитории, интеграция только через HTTP API.

Каждый компонент имеет CMakeLists.txt и include/ с публичными заголовками. Настройки передаются из main через Config в start; компоненты не подключают generated/local конфиги приложения. Зависимости указывать в CMake, не обращаться из components к main.
