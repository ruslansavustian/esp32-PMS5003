# Контроллер ESP32

Самостоятельный репозиторий C/C++ и ESP-IDF. Исходники — firmware/main/, make build / make flash / make monitor запускаются отсюда. scripts/esp.sh подготавливает SDK и определяет порт.

Это учебный проект русскоязычного Node.js/TypeScript разработчика. Объясняй небольшими шагами, не считай понимание подтверждённым наличием кода. Если рядом существует ../docs/, перед работой читай README.md, PROGRESS.md и нужный этап ROADMAP.md оттуда, после содержательной работы обновляй PROGRESS.md. При отдельном клонировании используй README.md этого репозитория.

ESP32-D0WD-V3 и PMS5003; точная схема платы не установлена. Не назначай GPIO и питание без проверки документации. Wi-Fi проверен на устройстве; HTTPS-телеметрия пока только собрана. Не утверждай физическую проверку без логов.

Секреты задаются в firmware/main/*.local.h, не коммитить и не выводить их. Не публиковать build/ и .local/: там могут быть секреты из прошивки. Backend живёт в отдельном репозитории, интеграция только через HTTP API.
